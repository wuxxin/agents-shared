# Benchmarks

Benchmark harnesses, comparative reports, and run archives for local inference services and Strata.

## Scripts

- **[run-local-benchmark.py](run-local-benchmark.py)** ([docs](run-local-benchmark.md)): Automates running and recording local service benchmarks (chat, completion, embedding, rerank, STT, TTS, image) across hardware configurations, updating `local-benchmark.md` and `local-benchmark.json`.
- **[benchmark-helper.py](benchmark-helper.py)**: Unified workload driver invoked by `assistants/local-*.sh test --benchmark` and `tests/test-fim-perf.py`.
- **[strata-baseline-cells.sh](strata-baseline-cells.sh)**: Captures paired Strata benchmark cells (`omp bench` Oracle A/B against the live chat service on port 20080) with per-cell journal slices and a README skeleton under `results/`.
- **[strata-env-battery.sh](strata-env-battery.sh)**: Runs Oracle A bench cells or Oracle D park-lab workloads across multiple Strata engine configurations by rewriting the env file per arm and restarting the launcher directly.
- **[strata-park-lab.py](strata-park-lab.py)**: Oracle D park-churn driver (`research/strata-v0.2.16-adoption-plan.md` §5) — warms a ~120k-token conversation, fires K prefix-sharing subagent conversations, probes the main conversation, and records reuse %, TTFT, and `/metrics` deltas per arm (A–E).

## Reports & Results

- **[local-benchmark.md](local-benchmark.md)** / **[local-benchmark.json](local-benchmark.json)**: Comparative local service benchmark report and structured cache generated by `run-local-benchmark.py`.
- **[results/](results/)**: Dated Strata benchmark run archives (raw logs, cell summaries, and `ANALYSIS.md` reports).

## Quick Examples

```bash
# Run local service benchmark in mock mode (writes to scratch/)
python3 benchmarks/run-local-benchmark.py --configs hip,vulkan,cpu --services all --mock

# Capture Strata baseline cells (from an isolated session not using the local model under test)
./benchmarks/strata-baseline-cells.sh --out <UTC-date>-gfx1100-<engine>-cells \
    --background "pulse stopped; bridge off; driver = deepseek-v4-flash"
```
