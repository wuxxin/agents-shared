## What this baseline says (and doesn't)

- The eviction symptom is real and quantified in production: ~62 forced ≥10k-token prefills and 47 evictions per 48 h, with park writes up to 5.8 s. Restores from RAM are fast (median 105 ms); the cost is concentrated in what eviction destroys.
- Prefix reuse on ordinary incremental turns works well (~95%, `cache_n` ≫ `prompt_n`) — the problem is only lifecycle, not steady state.
- These numbers come from mixed live traffic (Pulse + bridge + this session), so they are a **trend baseline**, not an A/B cell: per §3 of the plan, C0 Arm A still needs scripted cells (`strata-bench-remote.py --profile generation/mix`, `strata_bench.py` folder) with Pulse stopped and bridge off.
- Those scripted cells cannot run from this session: they require stopping/restarting the service, which ends any session served by qwen3.8-flash-next. Sequence per plan §7: capture real-usage data (this file), switch the migration session to DeepSeek Flash, then run C0 Arm A on 0.1.61 before installing v0.2.16+4.

## Tooling asymmetry found while preparing C0 Arm A (must-fix in the plan)

- **The benchmark we use for omp is `omp bench`** — strata-tuning §12.7 defines Oracle A/B/C as `omp bench qwen3.8-flash-next --profile generation --runs 3`, `… --profile mix --prefill-bytes 120000 --runs 6`, `… --detailed --par 4 …`. It is part of our installed oh-my-pi, speaks the OpenAI endpoint at :20080, and therefore runs **on both arms**: Arm A cells are taken on engine 0.1.61 before install, identical commands after ⇒ valid paired A/B, and directly comparable to the §13.3–13.4 `T4-FINAL` figures (same protocol, same model).
- The installed build ships **no `terminal/` tree**: `/usr/share/strata/` has only `serve/ src/ data/ cmake/ strata.py`, so upstream runners (`strata-bench-remote.py`, `conversation_cache_*.py`, `batch_*_test.py`) don't exist here — they arrive with v0.2.16 and become an *additional* post-cutover gate, never a baseline (no pre-upgrade reference can be produced).
- `scripts/run-local-benchmark.py` is **pre-strata** (zero mentions; its `chat` service = port 20080 with `proc_pattern: llama-server.*--port 20080`, lines 77-84). Keep it as a secondary box-continuity check via its history in `assistants/local-benchmark.json`; never the strata verdict.
- Arm A noise caveat, per strata-tuning §12.8: pre-flight is **user-mediated** — stop Pulse and any sidecar inference, disable the bridge (`OMP_BRIDGE_SETTINGS=/dev/null`), and move this session to DeepSeek Flash so `omp bench` measures an engine that isn't serving its own driver. Record all of it in the run README's `background:` field.
